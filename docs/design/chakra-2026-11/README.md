# Chakra UI rebuild (November 2026)

Screens after moving the UI from Tailwind classes to Chakra UI v3 components. The
colours, spacing and accessibility fixes from the
[Impeccable pass](../impeccable-2026-11/README.md) carry over through the Chakra
theme in `src/theme/`.

Taken with fictional demo data against a stubbed Supabase backend, light and dark
mode following the browser setting.
